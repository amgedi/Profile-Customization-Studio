# Changelog

User-facing changes by version.

## 0.3.3 — 9 October 2026

- Cohesive Design/Motion/Profile/Preview navigation, modern menus and scrollbars, responsive panels and accessible image/GIF uploads.
- Licensed scenes with theme-aware accents; richer rain, fog and atmospheric motion shared with animated Profile previews.
- Whole-scene GIF, WebM and MP4 composition, encoded previews, progress/cancellation and explicit target limits.
- Repeated-save collision protection preserves existing outputs with numbered companion files.
- Fixed an animated Profile frame-resource leak, keeping sustained playback responsive.
- GitHub profile graphics and ten statistics styles use fetched metrics; visible controls add real buttons and searchable icons.
- Thirteen-step startup tutorial and contextual Guide Me include button/icon insertion, keyboard access and reduced motion.
- Custom themes and backgrounds, supported window surface options and polished Local Studio assets/kits/history/variants.
- Optional donations in startup, Home, About and Settings; every feature remains free.
- Main Windows app runs directly, with no Launcher/helper binaries; matching AGPL source and third-party notices accompany it.

## 0.3.3-dev

- Studio logos follow theme palettes/custom accents across title bar, Home and About.
- Publication preparation adds source licensing, public documentation, CI, cleaned source packaging and security regression fixes. The source version is retained; installed historical builds are not overwritten.

## 0.3.2-dev

- More compact Home layout and consistently aligned recovery/quick-start content.
- Animation cards autoplay rendered frames; reduced-motion still frames and shared visible-card scheduling.
- Float returns to its starting position each cycle.

## 0.3.1-dev

- Guide Me supports custom colours/media and shared atmosphere effects.
- Improved motion timeline, Local Studio, tech stack and badge controls.

## 0.3.0-dev

- Platform-aware workspaces, Smart Adapt, local reusable data/history/variants and batch export tools.
- Restored licensed real-photo scenes while keeping unwanted procedural Night City and fake anime artwork out of the catalogue.

Entries describe changes supported by local source and preservation records, not published release history.
