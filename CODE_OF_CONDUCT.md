# Community conduct

Be respectful, constructive and welcoming. Discuss ideas and behavior without attacking people. Harassment, threats, discriminatory language, sexual harassment, doxxing and publishing private information are unacceptable.

Maintainers may edit or remove inappropriate content, close discussions, issue warnings or restrict participation. They should explain decisions where doing so does not expose private information, and consider severity, context and repeated behavior.

Report conduct concerns privately to the repository owner using the contact method listed on their GitHub profile. This repository has not yet been published; a dedicated private contact must be established before inviting community participation. Do not put sensitive reports in public issues.

These expectations apply in project issues, pull requests, discussions and other official project spaces. Good-faith questions and corrections are welcome.
