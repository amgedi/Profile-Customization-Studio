# Profile Customization Studio 🎨

A private workspace for experimenting with GitHub profile ideas before I throw them onto my actual profile xD.

## What belongs here

- animated profile banners and SVG experiments
- README layouts and reusable sections
- contribution-game ideas
- badges, stats, widgets, and profile visuals
- experiments that are not ready for the public profile repo yet

## How I want to use it

Keep rough experiments here, move polished assets into the repo that actually uses them, and avoid turning my public profile into a testing ground every five minutes 😭.

## Security and privacy

Do not use real tokens, credentials, private API responses, personal exports, or sensitive screenshots as placeholder content. Public-facing SVGs and Markdown should be treated as something that may eventually be copied into a public repository.

See [SECURITY.md](SECURITY.md) for the basic rules.
