# Security

This private repository is a design and experimentation workspace, not a place for secrets.

## Keep out of Git

Do not commit access tokens, API keys, cookies, private account exports, real authentication responses, private keys, or screenshots containing sensitive personal/account information.

SVG and Markdown experiments may eventually be copied into public repositories, so treat embedded links, text, metadata, and external resources as potentially public from the start.

If a secret is committed accidentally, revoke or rotate it immediately. Removing it in a later commit does not erase the historical copy.
