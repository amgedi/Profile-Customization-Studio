## Software dependencies

Dependencies are installed from the locked npm and Cargo registries rather than vendored here. React and React DOM use MIT; Lucide uses ISC; Tauri uses MIT OR Apache-2.0; Slint offers GPL-3.0-only or a commercial license. This AGPL source uses the compatible open-source Slint option. Each dependency retains its own license. Before distributing compiled binaries, collect and include full license texts for the exact bundled dependency graph. A source license alone does not replace dependency notices.

## 0.3.3 distribution

The main-app ZIP includes full production Node dependency license texts (NODE_LICENSES.txt), the Windows Studio native dependency graph (RUST_LICENSES.txt), and upstream license texts missing from individual crate packages (SUPPLEMENTAL_LICENSES.txt). Supplemental texts identify the exact source commit where available. The selectors source headers reference MPL-2.0; its full license text is included. Slint belongs to the preserved local Launcher source and is not included in the main-app binary package. Distribute the matching public source ZIP alongside the app to provide the corresponding AGPL source.

## Profile icons

The profile icon picker and exported button/icon SVGs use Lucide icons from the existing lucide-react dependency, licensed under ISC. See NODE_LICENSES.txt in packaged distributions and https://github.com/lucide-icons/lucide/blob/main/LICENSE. The GitHub glyph retains the existing PCS vector treatment.
